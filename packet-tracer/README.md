# Cisco Packet Tracer Lab

This folder contains the Cisco Packet Tracer implementation of the **Secure Government Office Network Lab**.

## Lab File

`secure-government-office-network.pkt`

## Implemented Environment

The Packet Tracer lab includes:

- Head Office network with multiple VLANs
- Administration, IT/Security, Internal Server, and DMZ segments
- Router-on-a-Stick inter-VLAN routing
- Access Control Lists (ACLs)
- SSH management restrictions
- Switch Port Security and unused-port hardening
- Warehouse branch using VLAN 70
- Simulated point-to-point WAN connectivity
- Static routing between sites
- Site-to-Site IPsec VPN between the Head Office and Warehouse

## Platform

The project was developed and tested using **Cisco Packet Tracer 9.0.0**.

> **Lab Note:** This environment is designed for cybersecurity learning and demonstration. The WAN and VPN are simulated within Packet Tracer and do not represent a production Internet connection or production-grade cryptographic deployment.
